About This Project

This website was created as part of a Swinburne University web-based data visualisation exercise (COS30045).

The project demonstrates the use of HTML for structure, CSS for presentation and JavaScript for interactive behaviour. All styling is kept in a single external stylesheet, and all behaviour is kept in a single external script, so that structure, presentation and behaviour remain separated.

What Comes Next

In later weeks this site will be extended with interactive data visualisations built using the D3.js library. The Televisions page is intended to host those visualisations.
